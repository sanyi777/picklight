## 2. 已验收功能

### 首页

- 可查看今日/选中日期待办。
- 周栏固定从真实今天开始展示 7 天。
- 点击未来日期只切换查看日期，不改变“今天”的定义。
- 标题按选中日期变化。
- 待办列表内部滚动。
- 可快速新增待办。
- 可快速捕捉零碎想法。
- 可快速进入专注页。
- 可通过右上角“重置”入口清空本地数据。

### 零碎

- 可新增零碎想法。
- 新增时可选择分类。
- 支持分类：灵感、随想、待办、分心、复盘。
- 可修改单条零碎内容。
- 可修改单条零碎分类。
- 可删除单条零碎。
- 待办类零碎会联动生成待办。
- 收纳箱内部滚动。

### 日程

- 可新增待办。
- 可完成/取消完成待办。
- 待办过多时内部滚动。
- 可添加每天最多两个锚点。
- 可修改锚点。
- 可删除锚点。
- 可手动拖动锚点进度。
- 当日复盘可归档到零碎-复盘。

### 专注

- 可展示当天锚点。
- 可修改/删除锚点。
- 已有两个锚点时不显示新增锚点入口。
- 可创建番茄钟，并填写本轮小事。
- 可手动设置番茄钟分钟数。
- 可使用 15/25/45 分钟快捷选择。
- 可开始、暂停、继续、完成番茄钟。
- 完成后可创建新一轮番茄钟。
- 可查看历史番茄钟。
- 可删除历史番茄钟。
- 可记录分心内容。
- 历史番茄钟下方大空白和页面抽搐问题已修复。

### 数据和业务规则

- 本地存储可保存应用状态。
- 数据重置会清空待办、零碎、锚点和番茄钟历史。
- 未完成待办会在应用加载时滚动到真实今天。
- 已完成待办不会滚动。
- 过期多天未完成待办会滚动到当前真实今天。
- 待办类零碎和待办系统联动。
- 修改待办类零碎会同步待办内容。
- 删除待办类零碎会处理对应待办。

## 4. 已知限制

- v0.1.0 是 MVP demo，不是正式发布版。
- 只支持本地存储。
- 不支持账号系统。
- 不支持云同步。
- 不支持多设备协同。
- 不支持系统通知和提醒。
- 不支持 AI 自动整理。
- 番茄钟主要保证前台体验，后台计时和退出恢复策略后续再完善。
- 仍需继续做更多真机尺寸回归。
- UI 文案和空状态仍可继续统一。
