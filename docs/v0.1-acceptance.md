# 拾光 TimeGleam v0.1 验收记录

版本：`v0.1.0`
验收完成：2026-07-26
平台：微信小程序
结论：真机体验通过，已发布线上版本

## 1. 发布结论

`v0.1.0` 已完成核心业务、自动化验证和用户真机体验，并发布为线上微信小程序。当前版本形成“快速记录、当天看见、锚点推进、番茄钟专注、本地备份”的完整闭环。

## 2. 已验收范围

### 首页

- 三栏导航中的首页入口正常。
- 七日日期轴和选中日期待办正常。
- 待办支持有截止时间和无截止时间。
- 每天最多两个锚点，支持修改、删除和手动进度。
- 快速捕捉通过屏幕中央模态卡片完成。
- 指引与数据入口位于同一行。
- 数据导出、合并导入和二次确认清空可用。

### 零碎

- 支持灵感、随想、待办、分心和复盘分类。
- 默认显示全部，分类筛选和创建时间倒序正常。
- 支持修改内容、修改分类和删除。
- 待办类零碎与首页待办联动。

### 专注

- 支持创建、开始、暂停、继续、完成、放弃和延长番茄钟。
- 暂停后剩余时间不继续减少。
- 切页面、切后台或锁屏后返回，可按时间戳恢复。
- 无锚点、一个锚点和两个锚点时，核心计时区域可显示和操作。
- 专注历史通过屏幕中央模态卡片展示。
- 关闭历史卡片后，计时按钮保持可操作。
- 支持修改和删除当天专注历史。
- 支持记录和管理当天分心内容。

### 数据规则

- 待办排序符合有时间、无时间、已完成三组规则。
- 未完成待办跨日滚动并清空旧截止时间。
- 待办和待办类零碎保持双向关联。
- 未完成锚点携带进度跨日，完成锚点次日清除。
- 当天以前的专注历史按规则清理。
- schema 2 备份可以导出和去重合并导入。

## 4. 当前限制

- 数据只保存在微信本地存储中。
- 不提供登录、云同步和多设备协作。
- 不提供系统通知和截止时间提醒。
- 不提供 AI 整理、情绪识别、标签、项目和复杂统计。
- 不提供零碎关键词搜索。
- 微信后台不会持续运行 JavaScript 计时器；计时恢复依赖时间戳计算。

## 5. 发布后工作

- 观察真实用户反馈和异常数据，不立即扩大功能范围。
- 下一轮需求必须回到“快速记录、当天看见、回到当前行动”的核心闭环评估。
- 新迭代开始前先更新 PRD、数据 schema 和验收标准。
